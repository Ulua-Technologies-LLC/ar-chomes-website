# AR-C Homes — website

Public website for **AR-C Homes LLC**, a residential land-development company building **Quarry Overlook** in Winston-Salem, NC.

**Live:** [ar-chomes.com](https://ar-chomes.com)

![AR-C Homes website](docs/screenshot.png)

## Highlights
- Single-file, dependency-free site (HTML + CSS + vanilla JS) — fast to load, easy to host
- English / Spanish toggle
- Responsive layout tuned for mobile
- Community and available-lot search, contact / request-info flow

## Stack & hosting
- HTML · CSS · JavaScript
- Cloudflare Pages (DNS on Cloudflare)

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
